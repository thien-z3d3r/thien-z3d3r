#### Selected Projects

- [`deep-learning-library-in-C-from-scratch`](https://github.com/thien-z3d3r/deep-learning-library-in-C-from-scratch) - N-dimensional tensor engine, reverse-mode autograd, layers, and optimizers in pure C99 with no runtime dependencies.
- [`LLS`](https://github.com/thien-z3d3r/LLS) - Lightweight Linux daemon in Rust that reads `/proc` directly and serves Prometheus-format metrics over HTTP.
- [`nnrust`](https://github.com/thien-z3d3r/nnrust) - Feed-forward neural network written from scratch in Rust using only the standard library.
- [`OpenEQ`](https://github.com/thien-z3d3r/OpenEQ) - System-wide parametric equalizer for Linux (PipeWire and PulseAudio) with Equalizer APO / Peace compatibility and AutoEQ profiles.
- [`supplychain-optimization`](https://github.com/thien-z3d3r/supplychain-optimization) - Supply chain and vehicle routing optimization platform built with Rust and Python.
- [`chip8-emulator`](https://github.com/thien-z3d3r/chip8-emulator) - CHIP-8 emulator written in Rust.
